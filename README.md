# hemang.xyz

Personal site. Single-page, terminal-flavored, light/dark with system default.

- `my_portifolio_website/` - the main site (Next.js, static)
- `just__chatting/` - the Just Chatting app, served at /just-chatting via the CHAT_URL rewrite in `my_portifolio_website/next.config.js`

Set `CHAT_URL` in Vercel for the /just-chatting zone rewrite to work.
